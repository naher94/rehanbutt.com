title: And...cut! The design process behind animation tools
date: 2025-05-07
location: Config
description: This talk explores the unconventional and evolving design processes behind the animation tools at Pixar and Walt Disney Animation Studios. Through case studies, we’ll showcase how innovative approaches to collaboration and iterative design address the ever-changing needs of artists, ultimately shaping tools that fuel the creation of groundbreaking films. Gain valuable insights and best practices for adopting flexible design processes that empower expert users—who not only rely on these tools but actively contribute to their development.
