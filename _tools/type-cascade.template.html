Type Cascade

Where the site decides its type. One tree for the whole site: every element that declares a type property, with the ones that declare nothing collapsed away. The Specimens sheet and the Atlas group type by what it renders as — this groups it by where it came from, so a value that is inherited from four levels up and one that was written on the element itself stop looking the same.

Pick a node to see what it sets, what it passes through, and which ancestor decided everything else.
